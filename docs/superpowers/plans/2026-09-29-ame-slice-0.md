**Tech Stack:** Python 3.12 · uv · pytest · ruff. Spike-only: pyrealsense2, faster-whisper (+ NVIDIA cuBLAS/cuDNN wheels), piper-tts, coqui-tts (XTTS-v2), F5-TTS, open3d, torch (CUDA 12.8 wheels), sounddevice, soundfile, numpy. All approved by the user on 2026-09-29 (CLAUDE.md rule 5).

## Global Constraints

- Python **3.12** exactly (`requires-python = ">=3.12,<3.13"`).
- **No dependency beyond the approved list above.** Anything else: stop and ask the user (CLAUDE.md rule 5).
- Code, comments, docs, commits: **English**. Anything AMe says or hears: **pt-BR**.
- **Never write recordings, frames, scans, or models into the repo.** The repo is in a OneDrive-synced folder. Use `%LOCALAPPDATA%\AMe\` only (spec §8.4).
- The runtime rule "raw audio/video is never stored" (spec §4, §5) applies to AMe itself. Spike recordings are test data the user makes deliberately; they stay in `%LOCALAPPDATA%\AMe\spikes\` and Task 12 asks the user whether to delete them.
- Work on branch `feature/ame-slice-0`. Commit locally per task. **Never push, tag, or merge into `main` without asking** (CLAUDE.md rules 4 and 6).
- Spikes are throwaway: no tests, no reuse from `src/`. Their output is the findings doc.
- Anything that needs the user's body — moving the camera, speaking, turning their head, listening — is a step that **stops and asks the user**. Do not simulate it.

## Review Focus

1. **Camera still on USB 2** → spike numbers would be silently wrong. `s1_camera.py` must refuse to measure on USB 2.x and say why (Task 6).
2. **CUDA unavailable on the RTX 5080 (Blackwell)** → libraries silently fall back to CPU and latency numbers mislead. Every GPU spike prints the device actually used and exits non-zero if CUDA was requested but is unavailable (Tasks 7, 9).
3. **Wrong microphone** (Bluetooth hands-free, or a silent default device) → garbage recordings. `record.py` requires an explicit device index and warns on near-silent clips (Task 5).
4. **Portuguese text on the Windows console** (cp1252) → garbled output or `UnicodeEncodeError`. Spikes force UTF-8 output; the message envelope must keep `você` literal in JSON (Tasks 3, 5).
5. **Recordings committed by accident** → personal audio synced to OneDrive and GitHub. Media extensions are git-ignored and verified with `git check-ignore` (Task 5).

```python
"""The JSON envelope every AMe service sends through the hub (spec §3)."""

from __future__ import annotations

import json
import re
import time
from dataclasses import dataclass, field
from typing import Any

TYPE_PATTERN = re.compile(r"^[a-z]+(\.[a-z_]+)+$")
_REQUIRED_FIELDS = ("data", "source", "ts", "type")


class MessageError(ValueError):
    """A hub message could not be decoded or breaks the envelope rules."""


@dataclass(frozen=True)
class Message:
    type: str
    source: str
    data: dict[str, Any] = field(default_factory=dict)
    ts: float = field(default_factory=time.time)

    def __post_init__(self) -> None:
        if not TYPE_PATTERN.match(self.type):
            raise MessageError(f"invalid message type: {self.type!r}")
        if not self.source:
            raise MessageError("message source must not be empty")

    def to_json(self) -> str:
        # ensure_ascii=False keeps pt-BR text readable in logs and on the wire.
        return json.dumps(
            {"type": self.type, "ts": self.ts, "source": self.source, "data": self.data},
            ensure_ascii=False,
        )

    @classmethod
    def from_json(cls, raw: str) -> Message:
        try:
            obj = json.loads(raw)
        except json.JSONDecodeError as error:
            raise MessageError(f"not valid JSON: {error.msg}") from error
        if not isinstance(obj, dict):
            raise MessageError("message must be a JSON object")
        missing = [name for name in _REQUIRED_FIELDS if name not in obj]
        if missing:
            raise MessageError(f"missing fields: {', '.join(missing)}")
        if not isinstance(obj["type"], str) or not isinstance(obj["source"], str):
            raise MessageError("type and source must be strings")
        if not isinstance(obj["data"], dict):
            raise MessageError("data must be a JSON object")
        ts = obj["ts"]
        if isinstance(ts, bool) or not isinstance(ts, (int, float)):
            raise MessageError("ts must be a number")
        return cls(type=obj["type"], source=obj["source"], data=obj["data"], ts=float(ts))
```

```python
"""Shared helpers for slice-0 spikes. Throwaway: never imported by src/ame."""

from __future__ import annotations

import importlib.util
import os
import re
import sys
import unicodedata
from pathlib import Path

DATA_FILES = Path(__file__).resolve().parent / "data"


def utf8_console() -> None:
    sys.stdout.reconfigure(encoding="utf-8")
    sys.stderr.reconfigure(encoding="utf-8")


def data_dir(*parts: str) -> Path:
    base = os.environ.get("LOCALAPPDATA")
    if not base:
        raise SystemExit("LOCALAPPDATA is not set; these spikes run on Windows only.")
    path = Path(base, "AMe", "spikes", *parts)
    path.mkdir(parents=True, exist_ok=True)
    return path


def read_lines(name: str) -> list[str]:
    text = (DATA_FILES / name).read_text(encoding="utf-8")
    return [line.strip() for line in text.splitlines() if line.strip()]


def normalize_words(text: str) -> list[str]:
    decomposed = unicodedata.normalize("NFKD", text.lower())
    plain = "".join(ch for ch in decomposed if not unicodedata.combining(ch))
    return re.sub(r"[^a-z0-9 ]+", " ", plain).split()


def word_error_rate(reference: str, hypothesis: str) -> float:
    ref, hyp = normalize_words(reference), normalize_words(hypothesis)
    if not ref:
        return 0.0 if not hyp else 1.0
    previous = list(range(len(hyp) + 1))
    for i, ref_word in enumerate(ref, start=1):
        current = [i] + [0] * len(hyp)
        for j, hyp_word in enumerate(hyp, start=1):
            substitution = previous[j - 1] + (ref_word != hyp_word)
            current[j] = min(previous[j] + 1, current[j - 1] + 1, substitution)
        previous = current
    return previous[-1] / len(ref)


def add_nvidia_dll_dirs() -> None:
    for package in ("nvidia.cublas", "nvidia.cudnn"):
        spec = importlib.util.find_spec(package)
        if spec is None or not spec.submodule_search_locations:
            continue
        bin_dir = Path(next(iter(spec.submodule_search_locations))) / "bin"
        if bin_dir.is_dir():
            os.add_dll_directory(str(bin_dir))
            os.environ["PATH"] = f"{bin_dir}{os.pathsep}{os.environ['PATH']}"
```

```python
# /// script
# requires-python = ">=3.12,<3.13"
# dependencies = ["pyrealsense2", "numpy"]

"""Spike S1: identify the RealSense camera and measure the frame rates it really delivers."""

import argparse
import time

import pyrealsense2 as rs
from _common import data_dir, utf8_console

INFO_KEYS = [
    rs.camera_info.name, rs.camera_info.serial_number, rs.camera_info.product_id,
    rs.camera_info.firmware_version, rs.camera_info.recommended_firmware_version,
    rs.camera_info.usb_type_descriptor,
]
MODES = {
    "depth 848x480@30": [(rs.stream.depth, 848, 480, rs.format.z16, 30)],
    "depth 1280x720@30": [(rs.stream.depth, 1280, 720, rs.format.z16, 30)],
    "color 1280x720@30": [(rs.stream.color, 1280, 720, rs.format.bgr8, 30)],
    "depth+color 848x480@30": [
        (rs.stream.depth, 848, 480, rs.format.z16, 30),
        (rs.stream.color, 848, 480, rs.format.bgr8, 30),
    ],
}


def measure(streams: list[tuple], seconds: float = 5.0) -> str:
    pipeline, config = rs.pipeline(), rs.config()
    for stream in streams:
        config.enable_stream(*stream)
    try:
        pipeline.start(config)
    except RuntimeError as error:
        return f"FAILED to start: {error}"
    try:
        frames, start = 0, time.monotonic()
        while time.monotonic() - start < seconds:
            pipeline.wait_for_frames(timeout_ms=2000)
            frames += 1
        return f"{frames / seconds:.1f} fps"
    except RuntimeError as error:
        return f"FAILED mid-stream: {error}"
    finally:
        pipeline.stop()


def record_sample(seconds: float = 10.0) -> None:
    path = data_dir("camera") / "sample.bag"
    pipeline, config = rs.pipeline(), rs.config()
    for stream in MODES["depth+color 848x480@30"]:
        config.enable_stream(*stream)
    config.enable_record_to_file(str(path))
    pipeline.start(config)
    try:
        start = time.monotonic()
        while time.monotonic() - start < seconds:
            pipeline.wait_for_frames(timeout_ms=2000)
    finally:
        pipeline.stop()
    print(f"recorded {path}")


def main() -> None:
    utf8_console()
    parser = argparse.ArgumentParser()
    parser.add_argument("--allow-usb2", action="store_true")
    args = parser.parse_args()

    devices = rs.context().query_devices()
    if len(devices) == 0:
        raise SystemExit("No RealSense camera found. Is it plugged in and is the SDK installed?")
    device = devices[0]
    info = {str(key).split(".")[-1]: device.get_info(key) for key in INFO_KEYS if device.supports(key)}
    for key, value in info.items():
        print(f"{key:30s} {value}")

    usb = info.get("usb_type_descriptor", "unknown")
    if usb.startswith("2") and not args.allow_usb2:
        raise SystemExit(f"Camera is on USB {usb}. Move it to a USB 3 port (Task 4) and re-run.")

    for label, streams in MODES.items():
        print(f"{label:28s} {measure(streams)}")
    record_sample()


if __name__ == "__main__":
    main()
```

```python
# /// script
# requires-python = ">=3.12,<3.13"
# dependencies = ["faster-whisper>=1.1", "nvidia-cublas-cu12", "nvidia-cudnn-cu12>=9,<10"]
# ///
"""Spike S3: detect the wake phrase "Ei, AMe" from STT transcripts."""

import argparse
import statistics
import time

from _common import add_nvidia_dll_dirs, data_dir, normalize_words, utf8_console

add_nvidia_dll_dirs()
from faster_whisper import WhisperModel  # noqa: E402

GREETINGS = {"ei", "hey", "eh", "e"}
NAME_FORMS = {"ame", "amy", "ami", "aime", "aimee", "amee"}


def is_wake(text: str) -> bool:
    words = normalize_words(text)
    return any(a in GREETINGS and b in NAME_FORMS for a, b in zip(words, words[1:]))


def main() -> None:
    utf8_console()
    parser = argparse.ArgumentParser()
    parser.add_argument("--model", default="small")

    model = WhisperModel(args.model, device="cuda", compute_type="float16")

        start = time.monotonic()
        segments, _info = model.transcribe(str(clip), language="pt", beam_size=1, vad_filter=True)
        text = "".join(segment.text for segment in segments).strip()
        latencies.append(time.monotonic() - start)
        kind = "pos" if clip.name.startswith("pos") else "neg"
        hits[kind].append(is_wake(text))
        print(f"{clip.name}  wake={is_wake(text)!s:5}  {latencies[-1]:.2f}s  {text}")

    detected = sum(hits["pos"])
    false_alarms = sum(hits["neg"])
    print(f"\ndetected {detected}/{len(hits['pos'])}, false alarms {false_alarms}/{len(hits['neg'])}")
    print(f"median latency {statistics.median(latencies[1:] or latencies):.2f}s")


if __name__ == "__main__":
    main()
```

```python
"""Spike S4b: XTTS-v2 cloned pt voice — quality and synthesis time per reply."""

import argparse
import os
import time

from _common import data_dir, read_lines, utf8_console

os.environ["COQUI_TOS_AGREED"] = "1"  # XTTS-v2 licence: non-commercial use, approved for this personal project.
import torch  # noqa: E402
from TTS.api import TTS  # noqa: E402


def main() -> None:
    utf8_console()
    parser = argparse.ArgumentParser()
    parser.add_argument("--loop", type=int, default=1, help="repeat the set (for S6)")
    args = parser.parse_args()

    if not torch.cuda.is_available():
        raise SystemExit("torch reports no CUDA device. Record torch.__version__ and the error; do not fall back silently.")
    print(f"torch {torch.__version__} on {torch.cuda.get_device_name(0)}")

    speaker = data_dir("voice") / "sample00.wav"
    start = time.monotonic()
    tts = TTS("tts_models/multilingual/multi-dataset/xtts_v2").to("cuda")
    print(f"XTTS-v2 loaded in {time.monotonic() - start:.1f}s")

    out = data_dir("tts", "xtts")
    for _ in range(args.loop):
        for number, reply in enumerate(read_lines("replies_ptbr.txt")):
            path = out / f"reply{number:02d}.wav"
            start = time.monotonic()
            tts.tts_to_file(text=reply, speaker_wav=str(speaker), language="pt", file_path=str(path))
            print(f"{path.name}  {time.monotonic() - start:.2f}s  {reply}")


if __name__ == "__main__":
    main()
```

```python
# requires-python = ">=3.12,<3.13"

"""Spike S4d: word timings from synthesized speech, as the basis for visemes."""

import argparse
import time

from _common import add_nvidia_dll_dirs, data_dir, normalize_words, read_lines, utf8_console

add_nvidia_dll_dirs()
from faster_whisper import WhisperModel  # noqa: E402


def main() -> None:
    utf8_console()
    parser = argparse.ArgumentParser()
    parser.add_argument("--engine", default="xtts", help="subfolder of tts/ to analyse")
    args = parser.parse_args()

    model = WhisperModel("large-v3-turbo", device="cuda", compute_type="float16")
    for number, reply in enumerate(read_lines("replies_ptbr.txt")):
        clip = data_dir("tts", args.engine) / f"reply{number:02d}.wav"
        start = time.monotonic()
        segments, _info = model.transcribe(str(clip), language="pt", word_timestamps=True)
        words = [word for segment in segments for word in segment.words]
        elapsed = time.monotonic() - start
        ordered = all(a.end <= b.start + 0.01 for a, b in zip(words, words[1:]))
        coverage = len(words) / max(1, len(normalize_words(reply)))
        print(f"\n{clip.name}  {elapsed:.2f}s  words={len(words)} coverage={coverage:.2f} ordered={ordered}")
        for word in words:
            print(f"  {word.start:6.2f}-{word.end:6.2f}  {word.word}")


if __name__ == "__main__":
    main()
```

```python
# /// script
# requires-python = ">=3.12,<3.13"
# dependencies = ["pyrealsense2", "numpy"]
# ///
"""Spike S5 capture: aligned depth+colour frames while the user slowly turns their head."""

import time

import numpy as np
import pyrealsense2 as rs
from _common import data_dir, utf8_console

SECONDS, KEEP_EVERY = 30, 5


def main() -> None:
    utf8_console()
    pipeline, config = rs.pipeline(), rs.config()
    config.enable_stream(rs.stream.depth, 848, 480, rs.format.z16, 30)
    config.enable_stream(rs.stream.color, 848, 480, rs.format.rgb8, 30)
    profile = pipeline.start(config)
    align = rs.align(rs.stream.color)
    depth_scale = profile.get_device().first_depth_sensor().get_depth_scale()
    intrinsics = profile.get_stream(rs.stream.color).as_video_stream_profile().get_intrinsics()

    try:
        for _ in range(60):  # let auto-exposure settle
            pipeline.wait_for_frames()
        input("Sit ~50 cm away, face the camera. Press Enter, then turn your head slowly left, right, up, down.")
        depths, colors, index, start = [], [], 0, time.monotonic()
        while time.monotonic() - start < SECONDS:
            frames = align.process(pipeline.wait_for_frames())
            index += 1
            if index % KEEP_EVERY:
                continue
            depths.append(np.asanyarray(frames.get_depth_frame().get_data()).copy())
            colors.append(np.asanyarray(frames.get_color_frame().get_data()).copy())
    finally:
        pipeline.stop()

    path = data_dir("scan") / "scan.npz"
    np.savez_compressed(
        path, depth=np.stack(depths), color=np.stack(colors), depth_scale=depth_scale,
        fx=intrinsics.fx, fy=intrinsics.fy, ppx=intrinsics.ppx, ppy=intrinsics.ppy,
        width=intrinsics.width, height=intrinsics.height,
    )
    print(f"saved {len(depths)} frames to {path}")


if __name__ == "__main__":
    main()
```

```python
# /// script
# requires-python = ">=3.12,<3.13"
# dependencies = ["open3d", "numpy"]
# ///
"""Spike S5 fuse: frame-to-frame RGB-D odometry plus TSDF fusion into a head mesh."""

import argparse
import time

import numpy as np
import open3d as o3d
from _common import data_dir, utf8_console


def rgbd(color, depth_mm, depth_scale, far_m, intensity):
    return o3d.geometry.RGBDImage.create_from_color_and_depth(
        o3d.geometry.Image(color), o3d.geometry.Image(depth_mm),
        depth_scale=1.0 / depth_scale, depth_trunc=far_m, convert_rgb_to_intensity=intensity,
    )


def main() -> None:
    utf8_console()
    parser = argparse.ArgumentParser()
    parser.add_argument("--near", type=float, default=0.3, help="metres; closer depth is discarded")
    parser.add_argument("--far", type=float, default=0.8, help="metres; farther depth is discarded")
    parser.add_argument("--voxel", type=float, default=0.002, help="metres")
    parser.add_argument("--show", action="store_true")
    args = parser.parse_args()

    scan = np.load(data_dir("scan") / "scan.npz")
    scale = float(scan["depth_scale"])
    intrinsic = o3d.camera.PinholeCameraIntrinsic(
        int(scan["width"]), int(scan["height"]),
        float(scan["fx"]), float(scan["fy"]), float(scan["ppx"]), float(scan["ppy"]),
    )
    volume = o3d.pipelines.integration.ScalableTSDFVolume(
        voxel_length=args.voxel, sdf_trunc=args.voxel * 5,
        color_type=o3d.pipelines.integration.TSDFVolumeColorType.RGB8,
    )

    start, pose, previous, failures = time.monotonic(), np.identity(4), None, 0
    for depth_raw, color in zip(scan["depth"], scan["color"], strict=True):
        metres = depth_raw * scale
        depth = np.where((metres >= args.near) & (metres <= args.far), depth_raw, 0).astype(np.uint16)
        gray = rgbd(color, depth, scale, args.far, intensity=True)
        if previous is not None:
            ok, transform, _info = o3d.pipelines.odometry.compute_rgbd_odometry(
                gray, previous, intrinsic, np.identity(4),
                o3d.pipelines.odometry.RGBDOdometryJacobianFromHybridTerm(),
                o3d.pipelines.odometry.OdometryOption(),
            )
            if not ok:
                failures += 1
                continue
            pose = pose @ transform
        volume.integrate(rgbd(color, depth, scale, args.far, intensity=False), intrinsic, np.linalg.inv(pose))
        previous = gray

    mesh = volume.extract_triangle_mesh()
    mesh.compute_vertex_normals()
    path = data_dir("scan") / "head.ply"
    o3d.io.write_triangle_mesh(str(path), mesh)
    print(f"{len(scan['depth'])} frames, {failures} odometry failures, "
          f"{len(mesh.vertices)} vertices, {time.monotonic() - start:.1f}s -> {path}")
    if args.show:
        o3d.visualization.draw_geometries([mesh])


if __name__ == "__main__":
    main()
```
